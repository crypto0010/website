What is Coprime Labeling?
  • Two integers are coprime if gcd(a, b) = 1, meaning they share no common factor other than 1.
  • A coprime labeling assigns positive integers to graph vertices such that adjacent vertices always have coprime labels.
  • Example: Path graph P₅ with labels [2, 3, 5, 7, 11] — every adjacent pair is coprime since they are all distinct primes.
Try it →
The Power Map g(x) = xᵐ
  • Labels evolve over time: fₜ₊₁(v) = fₜ(v)ᵐ.
  • Key theorem: if gcd(a, b) = 1 then gcd(aᵐ, bᵐ) = 1 — coprimality is preserved!
  • This means we can evolve labels indefinitely and the graph structure is maintained.
Try it →
GPU Acceleration
  • DCL operations are embarrassingly parallel — each vertex/edge can be processed independently.
  • 8 CUDA kernels achieving up to 263M ops/s on commodity hardware (RTX 3050).
  • Up to 7.9x speedup over CPU for batch operations at 1M elements.
