# Galaxy Hospital — Image Assets

Drop your files here using the exact names below. The website will pick them up automatically.

## Logo
```
images/logo.png          ← Main logo (transparent PNG, ~200-400px wide)
images/logo-white.png    ← White version for dark backgrounds (optional)
```

## Tips
- Use JPG for photos, PNG for logo (with transparency)
- Recommended: compress with https://squoosh.app before adding
- Minimum 500px wide for cards, 1200px+ for hero backgrounds
